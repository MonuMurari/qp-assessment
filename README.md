Grocery Booking Spring boot application
It has 2 modules with GET,POST,PATCH and DELETE endpoints. 
Below are modules and its features developed:
  1. Admin Responsibilities:
     - Add new grocery items to the system
     - View existing grocery items
     - Remove grocery items from the system by name
     - Update details existing grocery items by name
  2. User Responsibilities:
     - View the list of available grocery items
     - Ability to book multiple grocery items in a single order
     - See the order placed

Java 21 version is used in above app and MYSQL is used as database.
